Quick guide before you start

  1. Pick your Class & Episode — sets which skills and level caps apply.
  2. Adjust POW / VIT / DEX / INT — use the arrows or type values directly.
  3. Browse Pandaya Items — click a piece of gear to equip it and add its stats.
  4. Open Skills — spend Skill Points as you raise Character Level.
  5. Save Build — records your current stats, items and skills in Build Preview.
